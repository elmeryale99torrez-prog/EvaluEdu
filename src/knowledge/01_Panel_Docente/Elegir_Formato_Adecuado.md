# Cómo Elegir el Formato de Actividad Adecuado

## Respuesta rápida
Cada una de las **13 actividades** evalúa una operación cognitiva distinta. Usa esta tabla rápida para elegir la más potente según tu objetivo de clase.

## Comparativa de decisiones frecuentes

| Si quieres evaluar... | Elige este formato | En qué se diferencia |
| :--- | :--- | :--- |
| Afirmación rápida verificable | [[Actividad_01_Falso_Verdadero]] | 1 enunciado claro con contraste verdadero/falso. |
| Elegir 1 sola opción entre distractores | [[Actividad_02_Seleccion_Unica]] | Exactamente 1 respuesta correcta (2–6 opciones). |
| Discriminar varias respuestas válidas | [[Actividad_07_Seleccion_Multiple]] | 2 o más correctas sin revelar cuántas son. |
| Relacionar pares concepto ↔ definición | [[Actividad_03_Asociacion]] | Correspondencia 1 a 1 entre dos columnas. |
| Agrupar elementos en categorías excluyentes | [[Actividad_04_Clasificacion]] | Cada elemento pertenece solo a 1 categoría. |
| Contrastar 2 polos + lo que comparten | [[Actividad_12_Diagrama_Venn]] | Exige elementos exclusivos **y** una intersección común (`Ambos`). |
| Cruzar varios conceptos con varias propiedades | [[Actividad_11_Matriz_Doble_Entrada]] | Un mismo elemento puede cumplir múltiples columnas. |
| Orden cronológico o procedimental | [[Actividad_05_Ordenamiento]] | Secuencia estricta de 3 a 8 pasos. |
| Completar texto con vocabulario preciso | [[Actividad_08_Completar_Espacios]] | Banco cerrado de fichas táctiles (evita errores de tipeo). |
| Hallar 1 único fallo en pasos/enunciados | [[Actividad_09_Deteccion_Error]] | Auditoría crítica: exactamente 1 fragmento tiene error. |
| Subrayar varios términos clave leyendo | [[Actividad_10_Marcar_Palabras]] | Comprensión lectora: marcar múltiples términos en párrafo fluido. |
| Toma de decisiones ante un caso real | [[Actividad_06_Escenario_Decisiones]] | Etapas con consecuencias (*solo digital*). |
| Memoria activa sin pistas ni opciones | [[Actividad_13_Respuesta_Corta]] | Única actividad de evocación pura (*pure recall*). |
